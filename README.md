# Stock Portfolio Tracker

## 📌 About the Project
Stock Portfolio Tracker is a beginner-friendly Python project that helps users manage their stock investments. It allows users to add stocks, enter purchase and current prices, calculate total investment, and track profit or loss.

## ✨ Features
- Add stock details
- Store stock name, quantity, purchase price, and current price
- Calculate total investment
- Calculate current portfolio value
- Calculate profit or loss
- Save portfolio data in a CSV file
- View portfolio summary

## 🛠️ Technologies Used
- Python
- CSV File Handling
- Basic Financial Calculations

## 📂 Project Structure
```text
StockPortfolioTracker/
├── main.py
├── portfolio.csv
└── README.md
```

**Note:** `portfolio.csv` is created automatically when you add your first stock.

## ⚙️ How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python main.py
```

## 🖥️ How to Use
1. Select **Add Stock** to enter stock details.
2. Select **View Portfolio** to see your investment and profit or loss.
3. Select **Exit** to close the application.

## 🧮 Calculation
- Investment = Quantity × Purchase Price
- Current Value = Quantity × Current Price
- Profit/Loss = Current Value − Investment

## 🎯 Learning Outcomes
This project demonstrates Python functions, loops, conditional statements, exception handling, file handling, CSV operations, and basic financial calculations.

## ⚠️ Disclaimer
This project is for educational purposes only. Stock prices are entered manually and are not fetched from live market data. It does not provide financial advice.
